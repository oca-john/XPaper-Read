# XPaper-Read 数据说明

版本 1.0.5，2026-10-21。

本扩展提供内嵌 DeepSeek 网页聊天，以及可选的本地提取和模型 API 总结。

## DeepSeek 网页侧栏

- 打开侧栏的 DeepSeek 栏目会加载真实的 `https://chat.deepseek.com/`。页面正常使用 Firefox 管理的网站登录状态；插件不读取、保存或转发 Cookie、密码、网页登录令牌。
- 点击“填入阅读提示”后，当前标题、经过处理的网址、总结模板和固定阅读指令进入 DeepSeek 的页面输入框，网站能够读取这些信息。插件不点击网页发送按钮；用户自行在网页发送。
- 文章类型初判在本机进行，不产生分类 API 请求。类型明确或用户手动选择时使用对应的 Article / Review 模板；线索不足时，提示词包含两套模板和先判断类型再选择模板的指令。网页版不会为了分类主动读取论文正文；API 模式仅使用用户已读取的材料与元数据。
- 网页侧栏不调用插件设置中的 API，不读取或发送 API Key，不自行上传正文或文件。使用网页附件按钮上传的文件直接由 DeepSeek 处理。
- 网站数据处理由 [DeepSeek 隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html) 管理。可在 DeepSeek 自身设置中管理数据用于优化体验的选项。
- 网页输入工具只在本扩展的内嵌 DeepSeek 页面响应指令，校验父页面来源、消息来源和请求标识；不会在普通 DeepSeek 标签页执行填入操作。
- 只有点击“保存选中回答”才读取网页当前选中文字；核对并点击保存后写入本机笔记。没有自动抓取全部聊天记录或后台轮询回答。
- URL 保留论文定位所需的查询参数，移除常见登录/签名及追踪参数。此处理不能识别所有私有链接格式；实际内容可在“网址与提示词”中查看。
- 为显示内嵌页面，响应头兼容仅作用于 `chat.deepseek.com` 且直接父页面为本扩展 `sidebar.html` 的文档；仅调整嵌入相关策略，不改变 Cookie、普通标签页、其他 CSP 指令或浏览器全局设置。

## API 模式的本地处理

- 网页：读取用户当前标签页的正文、标题、可用学术元数据和全文 PDF 链接。
- PDF：下载用户选择的 URL，或读取用户主动选择的本地文件；使用内置 PDF.js 提取文字，按需将所选页渲染为图片。
- 未点击“精读”时，文章内容不会发送给模型。在线 PDF 的获取会向原文服务器发出请求，并可能使用该网站已有的登录状态；模型 API 不接收网站 Cookie。
- 当前完整原文与 PDF 图片仅存在侧栏内存中，关闭侧栏即释放。

## API 模式发给服务商的内容

只有用户点击“按我的模板精读”后，才向设置中指定的 API 地址发送：

- API Key，位于 Authorization 请求头；
- 当前预览的文献文字，以及图文模式下所选页的图片；
- 标题、可用作者/期刊/DOI 信息、材料范围、提取提示和来源 URL；
- 用户的相应总结模板与固定的学术阅读指令；类型不明确时包含 Article / Review 两套模板，供模型核实后选择；
- 对于长文，分段内容及后续综合所需的中间笔记。

发送的来源 URL 会移除查询参数和片段，以减少临时下载令牌泄露的可能；标题、正文、URL 路径及元数据仍属于发送内容。服务商如何处理这些数据，取决于该服务商的条款与隐私政策。

“测试连接”只向配置的 API 请求模型列表，并发送 API Key，不发送文献。

## 保存与删除

- 模板、设置、最近 30 条阅读笔记及来源信息存于 `browser.storage.local`；默认只显示最近 5 条，可在笔记栏目切换查看全部。
- 外观偏好（界面语言、明暗主题、主体配色）单独保存在本机，不传给模型、不上传云端。语言翻译在扩展内完成，不调用翻译服务，不改写模板、原文或笔记。
- 默认“跟随浏览器主题”仅读取 Firefox 向扩展页面提供的明暗偏好，不更改浏览器配置。新版默认模板的流程图指令随用户选择的模板发送；图源码在插件内仅作为文本显示、保存和导出，不执行脚本或访问外部绘图服务。
- API Key 默认存于 `browser.storage.session`，结束浏览器会话后清除。
- 用户勾选“在本机记住 API Key”时，Key 存于 `browser.storage.local`，没有额外加密；不会上传到 Firefox Sync。
- “清除已保存的 Key”删除本地与会话中的 Key；“清空阅读记录”删除已存笔记。
- 清除 Key 不撤销已经发出的模型请求或服务商端的 Key；需要撤销时请在服务商平台操作。
- 卸载扩展会由 Firefox 管理其本地扩展数据。

扩展没有运营方服务器、遥测、广告、后台阅读历史采集或第三方分析 SDK。用户主动打开笔记中的外部链接后，浏览器会访问相应网站。

本扩展不处理购买、账户充值、自动发表、自动投稿或第三方 OAuth 账号授权。网页登录直接发生在 DeepSeek 网站。
