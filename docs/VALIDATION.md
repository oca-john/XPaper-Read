## 静态告警的检查

没有关掉 Mozilla 的安全检查规则。源码不使用 `eval`，不把模型输出直接插入 DOM，不载入远程脚本。打包后的 5 条 `UNSAFE_VAR_ASSIGNMENT` 来自依赖库：

| 位置 | 原因 | 当前约束 |
| --- | --- | --- |
| `extract.js` 的 Readability 代码，2 条 | 库内部回退解析时使用 `innerHTML` | Readability 操作克隆的离线文档；本项目通过 serializer 获取 DOM 节点，只返回文字和元数据，不将该 DOM 插回网页 |
| `sidebar.js` 的 DOMPurify 代码，1 条 | 净化器内部构建解析节点 | Markdown 经 DOMPurify 白名单净化为 DocumentFragment；禁用图片、脚本、样式及事件属性；链接仅允许 HTTP(S) |
| `sidebar.js` 的 PDF.js 代码，1 条 | PDF.js 的 worker 回退机制含动态 import | worker 路径固定为扩展内资源；CSP 的 script-src 与 worker-src 都限制为 self |
| `vendor/pdf.worker.mjs`，1 条 | PDF.js 内部可选模块动态 import | 使用本地 worker，禁用 PDF.js 的 eval、Wasm、XFA 和 worker 页面渲染；不从 PDF 文档接受脚本路径 |

这些是人工检查后的依赖告警，不等于 Mozilla 已签名或审核批准。提交签名时仍可能被要求补充解释或调整实现。

## 尚未验证与已知边界

- 未使用用户的已登录 Firefox 配置，未验证特定账号、容器或隐私窗口的登录复用、实际网页回答或文件上传。登录直接由网站处理。
- 网站 UI、响应头和服务限制可能改变。输入框适配失败可复制提示词手动粘贴；不会自动点击发送或覆盖已有草稿。
- 插件使用 Firefox 支持的 MV2，以便仅调整本扩展直接内嵌 DeepSeek 文档的 frame-ancestors / X-Frame-Options；初版 MV3 无法修改已有的嵌入限制，已在真实浏览器中复现并更正。没有删除整条 CSP，没有改变普通标签页、其他站点或 Cookie。
- 未调用真实 DeepSeek API，账户权限、余额、真实流式稳定性及总结质量需用用户自己的 Key 试用。
- 没有逐一验证各出版商的付费页面、校园登录、验证码、PDF 重定向及 Cookie 隔离；提供导入文件/粘贴的回退方式。
- PDF 的复杂双栏、数学公式、表格、很小的图中文字可能解析不完整。图文模式会降低图片分辨率（最长边约 1600 像素），不是原始矢量文档；重要细节须回查原文。
- 原文定位标记由提示词引导生成，没有自动逐条核验模型引用。
- 长文先提取证据再综合，可能丢失细节；这不是经过科学效度验证的“完整理解”。
- 关闭侧栏会取消任务；记录按约 1 秒节流保存，最后少量内容可能尚未落盘。
- 未签名包只适合临时加载；永久安装需要 Mozilla 签名。未公开发布扩展。
- Firefox Android、Chrome 和其他浏览器不在此版本的支持范围。
