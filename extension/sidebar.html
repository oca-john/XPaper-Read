    阅读模板
    
        
    Article 梳理原创研究的设计、实施与结果链；Review 梳理综述的主题、证据、分歧与研究缺口。两套模板分别保存，网页版与 API 精读按文章类型使用。
    
        
    两套默认模板均要求结构化理解，并在末尾提供 Mermaid / Graphviz 分层图源码。网页版与 API 精读均使用胶囊控件选择文章类型。
    
        
    
          
          
        
    
        
        
        
    点击文本框展开编辑，点击外部收起。修改后需保存模板。
    
        
    保存和载入默认模板仅作用于当前选中的模板；切换时保留未保存的草稿。保存模板不需要 API Key。
    
      
    
      
    
      
    API 定义
    
      
    使用 DeepSeek 网页侧栏不需要 Key。如需自动提取全文、图文 PDF 和流式笔记，可在 DeepSeek 开放平台 创建密钥，或配置其他兼容 API。
    
      
    
        
        
    
        
        
    默认只保留在本次 Firefox 会话。勾选后存入浏览器本地存储，未经额外加密；不会同步到云端。
    
        
        
        
    支持兼容 Chat Completions 的 HTTPS 接口；密钥只发往这里。更换服务商时请同时更换对应密钥。
    
        
        
        
        
    默认 deepseek-flash 支持文字和图片。其他模型能否使用图文模式，以服务商能力为准。
    
        
    
        
        
    思考会占用输出额度并增加等待；建议同时提高最大输出 token。
    
        
    测试连接只请求模型列表，不发送文献、不生成内容。

    只有点击精读后，才会将当前预览的正文、所选 PDF 页面图片、来源信息及模板发往所配置的 API。无自建中转服务器、无遥测。API 使用按服务商规则计费。

    网页对话与 API 精读
    DeepSeek 栏目使用你自己的网页版登录状态；API 精读使用你配置的服务和密钥，由你自行充值。网页版的可用功能与使用限制由 DeepSeek 决定。
    
        
    模板与阅读记录
    模板由两种阅读方式共用。API 结果自动保存；网页版回答可用底部按钮保存。笔记默认展示最近 5 条，最多在本机保留 30 条，支持导出 Markdown。
    
        
    回到原文核对
    网址不代表已获取全文，数值、图表及引用需要核实。“期刊贡献”是基于文章的分析，不代表编辑或审稿人的真实录用原因。
    
        
    
          侧栏位置与快捷键
          
    右键 Firefox 的侧栏按钮 → 自定义侧栏 → 勾选“将侧栏移至右侧”。旧版布局可在侧栏标题菜单中选择“移动到右侧”。
    
          
    快捷键：Alt + Shift + Y
